# Lens Google Workspace add-on

This Apps Script add-on is the reliable Google Docs write path. Deploy the three files as a container-bound or Marketplace add-on. It requests access only to the current document and inserts pasted, previewed text at the user's cursor after an explicit button click.

The Chrome extension does not inspect or mutate Google Docs private editor internals. Until this add-on is installed, Copy is the supported fallback.
