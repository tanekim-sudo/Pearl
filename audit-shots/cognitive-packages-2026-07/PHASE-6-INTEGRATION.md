# Phase 6 integration checkpoint

The shared workflow is:

`preserved Material → grounded Cognitive Pull Request → selective candidate review → atomic merge/undo receipt → isolated higher-order ArtifactPatch → selective versioning → conformance test → signed declarative package → scoped publish approval → idempotent receipt`

The Cognitive Workflow Studio exposes each review boundary and hands accepted artifacts to Cognitive Packages. The companion exposes the same canonical commands and an `orchestrateCognitiveWorkflow` checkpoint that stops at candidate review; it cannot silently accept candidates or publish. Ask/Plan mode permissions, workspace snapshots, semantic review, effect observation, and the durable run ledger remain executor-enforced.

Extension flows use explicit page selection, shared vocabulary/package validators, verified local install history, and preserved web handoff for graph edits. No whole-page capture, package install, persistent teaching, or external publish bypasses its approval boundary.
