Pearl Everywhere

Select material on any permitted page, tell Pearl your goal, review candidates, and run only through an explicit command or GO.

Developer install: until Chrome Web Store publication, Chrome cannot install the unsigned ZIP directly from this website.

Install on desktop Chrome

  1. Download the ZIP from Pearl and unzip it.
  2. Open chrome://extensions.
  3. Enable Developer mode.
  4. Choose Load unpacked and select the unzipped folder.

Using the extension

Open Pearl Everywhere from Chrome, grant access only to the current site, select page text, and capture it from the page-edge Pearl or side panel. Add ordered Moves or Functions and optional Lens context, review the disclosure, then press GO. Results remain candidates until you explicitly keep, copy, insert, replace, annotate, or open them in Pearl. Spatial graph work uses a typed handoff to an explicit web Scene.

Move your library

Choose Get Pearl Everywhere in Pearl, review the Move, Function, Lens, dependency, and material counts, then download your .lens-library.json file. In the extension side panel choose Import library or drop the file on the import target. Review new items, exact duplicates, updates, and ID conflicts before confirming. Re-importing the same library is idempotent.

If a stable installed extension ID is configured, Send library to extension stages the same checksummed bundle for review. Otherwise the app automatically downloads the file. Full private source/provenance fields are excluded unless separately enabled during export.
