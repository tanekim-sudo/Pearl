Lens Everywhere

Capture selected page material, queue ordered lenses, preview the disclosure, and run only when you press GO.

Developer install: until Chrome Web Store publication, Chrome cannot install the unsigned ZIP directly from this website.

Install on desktop Chrome

  1. Download the ZIP from the Lens app and unzip it.
  2. Open chrome://extensions.
  3. Enable Developer mode.
  4. Choose Load unpacked and select the unzipped folder.

Using the extension

Open Lens Everywhere from Chrome, grant access only to the current site, select page text, and capture it. Queue lenses or a generator destination, review the disclosure, then press GO. Results remain previews until you explicitly copy, insert, replace, annotate, or open them in Lens.

Move your library

Choose Get Lens Everywhere in the Lens app, review the lens, generator, dependency, and material counts, then download your .lens-library.json file. In the extension side panel choose Import library or drop the file on the import target. Review new items, exact duplicates, updates, and ID conflicts before confirming. Re-importing the same library is idempotent.

If a stable installed extension ID is configured, Send library to extension stages the same checksummed bundle for review. Otherwise the app automatically downloads the file. Full private source/provenance fields are excluded unless separately enabled during export.
